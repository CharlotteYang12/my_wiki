# 背景

这篇论文之所以强调“RL 用的层数很小（2-5 层）”，主要是针对**从零开始训练的、基于状态（State-based）的强化学习算法**。 原因：
## 1. “视觉 RL”与“状态 RL”的区别

* **视觉 RL (Vision-based)：** 如果输入是像素（图像），网络必须很深（用 ResNet 或 ViT 做特征提取），否则根本看不懂图。比如pi-0.6 也有一部分模仿学习在里面
* **状态 RL (State-based)：** 如果输入是低维向量（如关节角度、速度），这是本文研究的重点。

  * 在 MuJoCo 等标准测试中，几乎所有经典框架（Stable Baselines3, CleanRL）默认都是* *2 层 MLP*。

  * 过去十年里，大家发现对于低维状态，加深网络到 8 层以上往往不仅不提速，反而会让性能下降（Overfitting 或梯度爆炸）。


## 2. PPO vs. CRL (本文方法) 的深度适配性对比

| 特性 | 传统 PPO / SAC | 本文 CRL 方法 |
| :--- | :--- | :--- |
| **训练目标** | 回归 Q/V 值，深度增加后对初始化和梯度缩放非常敏感。 | 对比分类，训练信号更稳定，更接近 CV / NLP 中可扩展的目标。 |
| **数据利用** | 在线/近在线采集，旧数据很快丢弃，深模型很难被充分训练。 | 可离线或离线混合训练，能反复利用数据。 |
| **数值范围** | Q/V 值可能从 0 变到几千，容易爆炸；自举误差会沿深层网络放大。 | 特征向量通常在固定范围内，数值更稳定。 |
| **稳定目标** | 缺少稳定的对比目标，TD 回归容易在深网络中崩溃。 | 用状态和目标的匹配关系构造对比目标。 |
| **历史经验** | SAC / PPO 等 TD 方法加深后常出现不收敛、Q 值爆炸、性能不如浅层网络，形成“RL 不需要深层网络”的经验偏见。 | CRL 是较新的范式，早期重点在验证方法可行性，过去较少系统探索深度缩放。 |
| **关键洞察** | 失败来自 TD / 回归目标，不等于 RL 本身不能变深。 | InfoNCE 这类对比分类目标更接近 CV / NLP 的可扩展训练目标，因此更适合堆深度。 |
| **深度潜力** | 4-8 层即达到瓶颈 | **1024 层**仍有收益 |

# 方法
## 概述
* **提供了一套“缩放配方” (Scaling Recipe)：**
  作者并没有只是简单地增加层数。他们整合了一套完整的架构：**残差连接 + 层归一化 (Layer Norm) + Swish 激活函数**。他们证明了这套在视觉领域标配的组合，在配合 **CRL 算法**时，能让 RL 模型突破层数限制。
* **训练出了前所未有的超深模型：**
  在此之前，几乎没人敢在 RL 里用 **1024 层**的网络。作者不仅训了，还通过 GPU 加速（JaxGCRL）解决了训练极其缓慢的问题。
* **发现了“涌现”行为：**
  这是最实在的成果。他们展示了 256 层的 Humanoid 智能体不再只是简单的“跑”，而是学会了\*\*“撑杆跳”、“翻墙”\*\*等复杂、具有高度协调性的动作。这些动作在 4 层或 8 层的模型中永远不会出现。
* **解密了“批次规模”的秘密：**
  他们第一次明确指出：RL 想要用大 Batch，前提必须是模型足够深。这为未来工业级大规模 RL 训练提供了指导。
